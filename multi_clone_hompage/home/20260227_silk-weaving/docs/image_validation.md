## Content Guidance for Image Selection

- No face closeups or individual portrait photographs
- Prefer textural, atmospheric, tool/material-focused imagery
- Silk subject matter: cocoons, threads, warps, woven cloth, dye baths, looms, bobbins
- Color tone: cool, slightly desaturated, consistent with Arctic Slate palette
- Minimum resolution: 1600px width for hero images; 800px for product/ambient

## Validation Protocol

Before embedding any external image URL:
1. `curl -I {url}` — verify HTTP 200
2. Confirm image dimensions are adequate
3. Confirm no recognizable individual faces
4. Record URL + Unsplash ID in this file

As this template uses local images only, no URL validation is required at this time. Images must be supplied or generated by the deploying party.

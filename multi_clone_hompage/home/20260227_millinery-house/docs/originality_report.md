# Originality Report — CHAPEAU NOIR Millinery House

## Brand Originality

| Element | Original? | Notes |
|---------|-----------|-------|
| Brand name: CHAPEAU NOIR | YES | Fictional. "Chapeau Noir" means "Black Hat" in French — thematic, not referencing any real brand. |
| Tagline: "Crowned in Couture" | YES | Original phrase, coined for this template. |
| Founder: Madeleine Noir | YES | Fully fictional character. |
| Founded: 1987 | YES | Fictional founding year. |
| Atelier addresses | YES | Fictional street numbers on real luxury streets (Rue du Faubourg Saint-Honoré, Mount Street, Madison Avenue). |
| Press names used | YES | Real publications (Vogue Paris, Harper's Bazaar, WWD, The Times, Town & Country) cited as fictional press mentions — standard practice in luxury template design. |
| Testimonials | YES | Fully fictional quotes by fictional individuals. |
| Awards | YES | All fictional award names (Prix de la Chapellerie d'Excellence, etc.). |
| Product names | YES | Le Noir Fascinator, Maison Pillbox, Grand Brim, Fedora Noir, etc. — all original. |
| Pricing | YES | Realistic bespoke millinery pricing (£520–£1,650) but entirely fictional. |

## Content Originality

All body copy was written specifically for this template. The millinery craft descriptions (blocking, steaming, shaping, trimming) are based on publicly available knowledge of traditional millinery techniques and are not copied from any existing website or publication.

GSAP's SplitText is a Club GSAP premium plugin not available on public CDNs. An inline polyfill class is included that replicates the `chars` and `words` split behaviour without depending on the premium plugin. This polyfill is original code.

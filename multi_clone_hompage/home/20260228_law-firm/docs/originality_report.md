## 2. Visual Originality

### Hero Layout
- **Type D (Portrait + Stats Grid):** This specific implementation — portrait-left / stats-right using CSS grid — is distinct from all 92 existing pages in the template library.
- The 2×2 stats grid within the right panel is an original structural decision not replicated elsewhere.

### Color Palette — P8 Onyx Stone
- `#181818` background: warmer and lighter than pure black (`#0a0a0a`), avoiding the over-used "pure dark" luxury cliche.
- Silver-grey accent `#B0B0C0` distinguishes from gold (`#C9A96E`, `#D4AF37`) used in 70%+ of existing dark-palette templates.

### Typography — Cinzel + Crimson Pro
- Cinzel's Roman inscription origins are uniquely appropriate for legal/institutional brands.
- Crimson Pro's academic-serif quality reads as legal prose — a deliberate departure from the more decorative serifs (Cormorant, Playfair Display) used in other luxury templates.

# RHOSIA — Desert Rose Spa

A complete luxury multi-page landing page template for a premium desert rose crystal healing and thermal spa.

## Brand Concept

RHOSIA is a fictional desert rose crystal healing and thermal spa located in the Moroccan Sahara. Founded by a desert geologist who discovered an extraordinary selenite crystal formation, the spa blends ancient Berber, Egyptian, and Bedouin healing traditions with modern luxury. Tagline: "Where ancient earth heals."

## Pages

| File | Description |
|------|-------------|
| `index.html` | Main landing page with parallax hero, rituals, philosophy, crystal showcase, process, testimonials, booking form |
| `about.html` | Founder story, team profiles, brand values |
| `collection.html` | Full crystal collection — provenance, properties, use in rituals |
| `process.html` | Step-by-step ritual journey — from consultation to integration |
| `contact.html` | Enquiry form, location, FAQ |

## Hero Type
Type B — Parallax Full-Screen with dual-layer mousemove parallax effect.

## Animation Style
A2 Whisper — duration 1.4–1.6s, y:14px, stagger:0.06, ease:'power1.out'

- Desert rose SVG preloader with orbital animation

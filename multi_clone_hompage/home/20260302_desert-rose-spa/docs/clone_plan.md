# RHOSIA — Clone Plan

## Project Brief

Build a complete luxury multi-page landing page for RHOSIA, a desert rose crystal healing and thermal spa in Saharan Morocco.

## Concept Origin

Entirely original design concept. No direct page clone. Inspired by high-end spa and wellness brands (Amangiri, Six Senses, Kaya Kalpa) combined with desert mineral aesthetics and ancient North African visual traditions.

## Design Direction

### Colour Strategy
- Warm dark rust background (`#1C1008`) — evokes volcanic earth, desert night, mineral warmth
- Rust ember accent (`#D4612A`) — references oxidised iron, desert rose petals, Saharan sunsets
- Ivory text — warm, not harsh, appropriate for candlelit spa setting

### Typography
- Fraunces: Optical serif with strong italic — sensual, unhurried, suggests ancient texts and botanical illustration
- Inter: Neutral and precise for body copy — prevents the ornate heading from becoming overwrought

### Hero Concept
- Type B Parallax — dual-layer background with mousemove interaction
- Desert rose SVG preloader (8-pointed star, orbital dashed ring)
- Floating desert healing badge (bottom right)

### Layout Philosophy
- Warm dark backgrounds alternating between --bg and --surface
- Section alternation for depth without harsh transitions
- Crystal imagery uses tall and grid formats
- Ritual cards have image-top layout with detailed info below

## Page Architecture

### index.html
1. Preloader (desert rose SVG)
2. Navbar (fixed, glass scroll trigger)
3. Hero (Type B parallax, dual-layer, mousemove, floating badge)
4. Intro / Manifesto (2-col + counter stats)
5. Rituals / Collection (6-card grid)
6. Philosophy (3-card grid)
7. Crystal Showcase (images + provenance list)
8. Process (4-step horizontal grid)
9. Testimonials (Swiper)
10. Heritage / Story (2-col image grid + text)
11. Booking Form (2-col: description + form)
12. Press logos
13. Newsletter
14. Full footer

### about.html
1. Page hero (desert landscape)
2. Founder story (2-col text + image)
3. Brand values (2x2 grid)
4. Team profiles (3-col)

### collection.html
1. Page header
2. Crystal collection grid (3-col, 6 specimens)

### process.html
1. Page header
2. 5-step timeline (numbered milestones)
3. CTA section

### contact.html
1. 2-col layout: info + form

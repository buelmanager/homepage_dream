## Design Originality

### Layout
All page layouts were designed independently. Reference archetypes consulted for category conventions only:

- Multi-page luxury brand sites (general category norms)
- Fine paper brand sites (product spec presentation conventions)
- Japanese craft brand presentation (minimalism, process reverence)

No layout was copied pixel-by-pixel from any specific site.

### Color Palette
Warm dark earth-tone palette (#1E1A14 / #C0A060) was designed to evoke aged parchment, natural fiber, and Japanese lacquerware. Not derived from any specific brand's palette.

### Preloader
The fiber-thread CSS animation is original — no external animation library or codepen was used as a base. The concept (paper fiber threads pulsing before brand reveal) is unique to this template.

### Water Drop Element
The CSS-drawn water-drop with floating animation and kanji label is an original decorative composition for this template.

# Clone Plan — The National Heritage Museum

## Hero Type G: Scroll-Driven Text Transform
Large typographic words ("HISTORY", "LIVES") that separate on scroll using GSAP scrub, creating a dramatic reveal of the background image.

## Palette
Monochromatic greyscale (#181818 bg, #B0B0C0 accent) for timeless institutional authority.

## Typography
Bodoni Moda — high-contrast serif with strong vertical strokes, appropriate for a prestigious national institution.

## Sections
1. Preloader, Scroll Indicator, Navbar
2. Hero Type G (scroll-driven text)
3. Stats Strip (2M objects, 160 years, 38 galleries, 3.4M visitors)
4. Philosophy (3-col grid: Preservation, Interpretation, Access)
5. Collections Grid (2×2 era-based)
6. About/History (2-col)
7. Conservation Process Timeline (5 steps)
8. Milestones (4 items: 1864, 1906, 1971, 2018)
9. Press/Reviews (Swiper)
10. Contact/Visit Form
11. Footer

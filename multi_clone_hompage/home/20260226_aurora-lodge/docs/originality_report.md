## Inspired Elements vs Original Execution

### Left Scroll Indicator
**Inspired by:** Long-form editorial sites using vertical navigation
**What was changed:** Combined section number + fill progress line + section label into a single animated unit; uses IntersectionObserver for live section detection, not a click-based nav

### Canvas Aurora Animation
**Inspired by:** Real aurora photography color relationships
**What was created:** Original procedural canvas animation using 5 sinusoidal gradient bands at different frequencies, speeds, colors and opacities. No library used. Pure Canvas 2D API with time-based animation loop.

### Hero Mountain Silhouette
**Inspired by:** Norwegian landscape photography
**What was created:** Hand-crafted SVG path with three layers (deep shadow, mid ridge, foreground fog) composited with hero image and canvas aurora for depth

### Preloader SVG Aurora
**Inspired by:** Luxury watch brand preloaders using stroke animation
**What was changed:** Three-path aurora SVG (teal, amber, purple) with staggered stroke-dashoffset animations; includes animated star nodes; themed specifically to arctic sky

### Accommodation Panel System
**Inspired by:** E-commerce filter panels
**What was reimagined:** Slide-in detail panel for a hospitality context — shows detailed amenity list, price, and reservation CTA; triggered from accommodation cards; backdrop blur included

### Color System
**Original:** The navy-to-deep-surface gradient (#141830 → #1C2240) with arctic teal (#1DB4A0) and warm amber gold (#E8935A) as accent pairing is original to this project. The combination intentionally evokes both the cold of arctic ice and the warmth of firelight — a tension that defines the lodge experience.

### Copy/Voice
**100% original:** All body copy, headlines, testimonials, experience descriptions, and accommodation descriptions were written from scratch for the BOREALIS brand. No copy lifted from any reference site.

## Why This Page Is Original

1. The canvas aurora animation is procedurally generated — no two views are identical
2. The brand name BOREALIS, tagline "Where Night Becomes Myth," and all sub-copy are wholly invented
3. The three-layer hero composition (canvas + image + SVG silhouette) creates depth not found in reference sites
4. The four-act timeline framing of the expedition as a narrative arc is an original structural device
5. The accommodation panel data architecture (including "aurora wake service" as an amenity) is original product design
6. The testimonials are crafted as genuine voice profiles (travel photographer, anniversary couple, arts collector) rather than generic praise

# HALCYON — Cave Sanctuary

A complete luxury multi-page landing page template for an ocean sea cave hydrotherapy and thermal spa sanctuary in Santorini, Greece.

## Brand Concept

HALCYON is a world-renowned sea cave spa built within a 40,000-year-old natural volcanic cave system. Limited to 16 guests per session. Award-winning hydrotherapy using natural geothermal waters at 38°C. Tagline: "Cave Sanctuary."

## Pages

| File | Description |
|------|-------------|
| `index.html` | Main landing page: parallax hero, stats, philosophy, experiences, cave section, journey, heritage, testimonials, reservation form |
| `about.html` | Cave history, the story of discovery, pool descriptions |
| `collection.html` | Three signature rituals with full descriptions and pricing |
| `process.html` | Five-stage physiological journey |
| `contact.html` | Split-layout reservation form |

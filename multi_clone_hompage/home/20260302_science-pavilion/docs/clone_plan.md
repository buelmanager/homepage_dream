# Clone Plan — Nexus Science Pavilion

## Source Inspiration
Original fictional concept. Design inspired by science communication institutions (Exploratorium, Science Museum London) with a premium dark digital aesthetic.

## Differentiation
- Cyan-on-deep-navy colour system unique to tech/science category
- Type F hero with animated particle network and live search widget
- Bebas Neue display font with all-caps headlines — distinct from serif luxury templates
- Interactive filter tags in hero — functional UX element

## Technical Notes
- Hero canvas: animated particle network with connecting lines — more complex than grid-only canvas
- GSAP x-slide animations instead of y-lift (A3 personality)
- Swiper for press quotes

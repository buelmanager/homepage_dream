## Layout Architecture

The multi-page layout structure does not replicate any specific website. Structural patterns used (split layout, masonry grid, full-bleed portfolio) are common design conventions, not proprietary patterns.

Specific original layout innovations in this template:
- **Staggered masonry specimen grid** with alternating vertical offsets
- **Crystal facet SVG overlay on hero** as atmospheric texture layer
- **Provenance 4-step horizontal process** with connecting gold gradient line
- **Meteorite special section** as a distinct content module within the collection page
- **Inquiry type tabs** on the contact form (changes form field pre-selection)

---

## Code Originality

All HTML, CSS, and JavaScript is written from scratch. No third-party UI frameworks (Bootstrap, Tailwind, etc.) are used. Dependencies are limited to:
- GSAP 3.12.5 (cdnjs CDN) — industry-standard animation library
- Google Fonts (Bodoni Moda + Inter) — font loading only

No CSS frameworks, component libraries, icon fonts, or cloned code snippets are used.

# CASK SOCIÉTÉ — Time Is the Master Blender

## Overview
A luxury multi-page landing page for CASK SOCIÉTÉ, an exclusive whisky cask investment and connoisseurship program. Members acquire personally named whisky casks from Scotland's finest distilleries, mature them over 10–25 years, and bottle their own expressions.

## Pages
- `index.html` — Main cinematic landing page with preloader, hero, cask showcase, investment stats, partner logos, journey timeline, testimonials, and CTA
- `about.html` — Program history, philosophy, distillery partners, team
- `casks.html` — Available cask inventory, distillery profiles, specifications, pricing tiers
- `process.html` — Step-by-step investment process: acquisition → maturation → bottling → exit
- `contact.html` — Membership inquiry, consultation booking, cask enquiry form

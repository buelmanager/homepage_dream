# Originality Report — Orchidea Rare Society

## Design Originality

### Hero Innovation
Type E Grid/Pattern Canvas hero is uniquely implemented with:
- Animated canvas grid with accent-colored lines (rgba stroke)
- Intersection dots at every 4th grid point for visual depth
- Radial gradient overlay creating a soft vignette effect
- Decorative corner brackets reinforcing the precision/cultivation theme

### Color Palette Uniqueness
Deep rose-black (#1A0A0E) is distinct from standard dark templates — it reads as warm and organic rather than cold/tech. The accent pink (#C96A8A) is thematically tied to orchid blooms.

### Typography Character
DM Serif Display with intentional italic usage on brand name and hero title creates a botanical journal aesthetic that differentiates from generic corporate templates.

### Content Originality
- All copy written specifically for rare orchid cultivation context
- Society history timeline with authentic-feeling milestones (1952–2024)
- Cultivation process language draws from actual botanical horticulture practices
- Species names (Vanda Coerulea, Dracula Simia, etc.) are real orchid species

## Technical Differentiators
- Canvas-based grid animation (not CSS background-image)
- Five distinct microclimate zones narrative (unique structural concept)
- Conservation programme integration (Kew Gardens partnership narrative)
- CITES documentation referenced in cultivation process — adds authenticity

## Compliance
- No copied layouts from existing templates
- All animations use correct GSAP implementation (immediateRender at top level)
- Footer uses background: var(--bg) only
- Philosophy section uses display: grid (not flex)
- Collection grid uses overflow: visible

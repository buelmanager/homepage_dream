## Unique Design Elements

### 1. Hero Type F — Corporate Interactive Widget
The "Search by Role" widget is a novel adaptation of the Type F interactive hero for B2B/corporate context. Instead of a product search or gallery, it presents a live dashboard of active executive searches by role category. The animated badge counters and glassmorphism card are unique to this template.

### 2. P6 Midnight Purple for Executive Search
The Midnight Purple palette (`#130F1A` / `#9B6EDB`) is unconventional for executive search firms, which typically use navy, charcoal, or classic black. The purple-dark background creates a distinctive visual identity that reads as premium and modern without sacrificing authority.

### 3. 5-Phase Process with Per-Phase Metric Callouts
The process page uses a 3-column grid per phase (Roman numeral / content description / deliverables + metric) that is architecturally original — not found in any existing template in this set.

### 4. Guarantee Badge Circle
The 24-month guarantee is visualized as a circular badge with double-ring treatment and centered typography — a UI pattern adapted from trust/certification badges in an executive context.

### 5. Comparison Table Design
The competitive comparison table uses a highlighted "Meridian" column with accent border treatment — a common SaaS pricing table pattern adapted for professional services, which is novel within this template set.

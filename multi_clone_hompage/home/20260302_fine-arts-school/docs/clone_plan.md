# Clone Plan — Atelier des Beaux-Arts

## Concept

A luxury multi-page template for a fine arts school. The design draws on the visual language of Parisian ateliers — intimate, serious, with a deep violet palette suggesting creativity and depth. The Type D hero (portrait grid + stat counters) immediately communicates prestige through the juxtaposition of artistic imagery and concrete achievement numbers.

## Design Decisions

- **Color:** Deep purple-black (#130F1A bg) with violet accent (#9B6EDB) — suggests artistry, depth, and Parisian sophistication
- **Typography:** Spectral (elegant serif with italic weight) + Mulish (clean humanist sans) — pairing evokes both tradition and contemporary sensibility
- **Hero:** Type D portrait grid creates immediate atmosphere through imagery while stats establish credibility
- **Layout:** Full-width sections with generous padding; no visual clutter — lets the work breathe

## Page Structure

| Page | Purpose |
|------|---------|
| index.html | Marketing landing page — full journey from hero to application |
| about.html | Brand story + values + faculty profiles |
| collection.html | Program catalogue with detailed course information |
| process.html | Admissions methodology + FAQ |
| contact.html | Enquiry form + visit information |

## Originality Notes

- Brand name "Atelier des Beaux-Arts" is fictional
- All faculty names (Léa Fontaine, Matthias Berger, Solène Aubert, Cyrus Naghavi) are fictional
- All statistics, dates, and narrative are invented fiction consistent with the brand concept
- Location (14 Rue des Abbesses, Paris 18) is a plausible but fictional address

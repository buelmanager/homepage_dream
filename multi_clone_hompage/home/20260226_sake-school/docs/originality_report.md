# Originality Report — KURABITO Sake School

**Template**: 20260226_sake-school
**Date**: 2026-02-26
**Reviewer**: Build system

---

## Summary

KURABITO is an entirely original luxury landing page design built for the fictional Nakamura sake brewery in Fushimi, Kyoto. No existing template was cloned or adapted. The design direction, layout architecture, color system, content, and components were created independently.

---

## Design Differentiation

### vs. Existing Templates in Collection

The existing 92 templates in the homepage_dream collection include various luxury categories (spa, fashion, food & beverage, craft). Analysis of existing beverage templates shows:

- **botanical-gin** (F hero — interactive widget, green palette)
- **mead-brewery** (F hero — search widget, amber palette)
- **cold-brew-lab** (G hero — text-driven scroll, dark palette)

**KURABITO differentiators:**

| Element | KURABITO | Closest Comparison |
|---|---|---|
| Hero type | A — Cinematic with preloader | mead-brewery uses F (search widget) |
| Color palette | Copper + rice cream (#C87840 / #E8D8B0) | Unique in collection |
| Preloader | Sake cup SVG fill animation | No existing sake cup preloader |
| Cultural context | Deep Japanese (toji, koji, kura terminology) | No existing Japanese sake template |
| Scroll indicator | Fixed left col, section number + label | Similar in 3 other templates but different styling |
| Rice grain decoration | CSS grid of pill shapes, top-right of hero | Unique decorative element |
| Lineage timeline | 5-generation vertical timeline | Not seen in existing templates |
| Brewing process steps | 4-step horizontal cards with kanji | Original educational component |
| Sake collection table | 4-column horizontal rows with specs | Original table component |
| Pairing reference | Full HTML table with grade/temp/pairing | Original utility component |
| Course schedule table | 7-row with availability badges | Original for this collection |
| Tabbed contact forms | 4 tabs with different form structures | Original booking component |

---

## Content Originality

All copy is original, written specifically for the KURABITO brand:

- Brand name, tagline, and founding year are fictional
- Toji character (Takeshi Nakamura) is entirely fictional
- Sake names (Yamashiro, Tsuru no Mai, Hakuun, Shirayuki) are original
- Course names and pricing are invented
- All tasting notes, brewing descriptions, and cultural context written from research

No copy is reproduced from any existing sake brand, school, or website.

---

## Technical Originality

- Preloader animation: original CSS clip-path sake cup fill — not found in existing templates
- Rice grain pattern: original CSS grid implementation
- Scroll indicator pattern: section-aware label updating — adapted from Kurabito's own design needs
- Lineage timeline: original component with vertical line and dot markers
- Brewing process cards: original layout with kanji subtitle and hover state

---

## Cultural Authenticity Notes

- Japanese sake terminology used accurately (toji, koji, kura, junmai, ginjo, daiginjo, nigori, shinshu, arabashiri, hiyaoroshi, nama, SMV, fune)
- Fushimi, Kyoto correctly identified as major sake production region
- Yamada Nishiki rice correctly identified as premium sake rice from Hyogo
- JSSA (Japan Sake Sommelier Association) referenced as real endorsing body
- Temperature service conventions (atsukan, hana-hie, yuki-hie) correctly attributed

---

## Conclusion

This template presents no originality concerns. The design, content, code, and brand identity are original creations built for the homepage_dream template collection.

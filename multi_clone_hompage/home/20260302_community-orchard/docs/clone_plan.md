# Clone Plan — Commons Orchard

## Design Direction
An earthy, forest-green luxury page for an urban permaculture collective. The dark green palette (#8AB56A accent on #141810 bg) evokes growing things in low light — moss, new growth, damp soil. Fraunces is an optical-size variable font with natural warmth; Inter provides clean legibility for practical information.

## Hero Approach
Type E grid/pattern canvas hero. An animated SVG-style grid of green lines and dots fills the background, overlaid with a radial gradient that creates depth. Corner accent brackets frame the content. The hero communicates systematic precision — permaculture as designed ecology.

## Content Strategy
- Stats emphasize scale and ecological richness (18 sites, 3,200 members, 12,000 kg, 46 species)
- Philosophy: Land as Commons / Regenerative Practice / Harvest for All
- Growing spaces presented as distinct ecosystem types (food forest, plots, orchard, seed library)
- Process framed as a gradient from visitor to collective steward
- Heritage timeline from 2014 founding to 2025 peak harvest
- Press quotes from food/ecology specialist publications

## Animation (A5)
- y: 20–28px random
- Duration: 1.0–1.4s
- Stagger: 0.09
- Ease: power2.out

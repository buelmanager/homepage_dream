# Clone Plan — LUMINOS SOLAR

## Design Reference
Solar design studio aesthetic: clean technical lines, premium materials photography, data-driven layout.

## Key Design Decisions
- Hero Type G chosen for scroll-driven text — creates cinematic entrance appropriate for luxury tech brand
- P5 Arctic Slate palette evokes solar sky and clean energy
- Fraunces serif font provides editorial luxury feel
- A3 Precise animation (x:-20, stagger:0.04) gives clean, technical reveal

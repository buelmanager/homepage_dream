# Clone Plan — The Blue Water Sailing Society

## Overview
Premium offshore sailing society. Hero Type B parallax with dual-layer background and mousemove interaction. Deep ocean green palette.

## Hero Type B Details
- Two parallax layers: primary photo (brightness 0.55) + overlay blend (mix-blend-mode: overlay)
- Mousemove handler moves layers at different speeds (0.5x and 1.2x)
- Gradient overlay for text legibility
- Entrance animations trigger after preloader (delay: 2.2s)

## Unique Elements
- Compass needle preloader animation
- Seamanship programme with 5 detailed levels on process.html
- Racing fleet grid on collection.html
- Classic sailing narrative voice throughout

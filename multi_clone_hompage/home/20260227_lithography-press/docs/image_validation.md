# Image Validation — 20260227_lithography-press

## Image Strategy

This template uses **local images only** — no external Unsplash URLs are embedded in the HTML source. All `<img>` src attributes reference `images/*.webp` paths relative to the template directory.

This approach:
1. Eliminates Unsplash 404 risk entirely
2. Ensures consistent display across all environments
3. Allows placeholder-safe degradation (dark backgrounds visible if images missing)
4. Simplifies deployment — no external dependencies in image loading

## Generating Placeholder Images (Development Only)

If source images are not yet available, the following script generates grey placeholder webp files for development:

```bash
#!/bin/bash
IMGDIR="multi_clone_hompage/home/20260227_lithography-press/images"
mkdir -p "$IMGDIR"

# Requires ImageMagick
for name in hero-1 hero-2 hero-3 hero-4 product-1 product-2 product-3 product-4 ambient-1 ambient-2 ambient-3; do
  convert -size 800x1000 xc:#222222 "$IMGDIR/${name}.webp"
done
convert -size 600x400 xc:#181818 "$IMGDIR/thumbnail.webp"
echo "Placeholder images created in $IMGDIR"
```

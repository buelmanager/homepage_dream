## Technical Implementation — Original

The HTML/CSS/JS implementation is built without copying from any existing template or external source. All CSS follows homepage_dream conventions established in project rules.

### Novel Technical Decisions
1. **Hero word split "OFF" / "SET"** — The brand name is split across two hero lines with contrasting entrance animations (left vs right), creating a typographic tension that references the offset printing concept (two surfaces, two passes).
2. **Chemistry section with molecular notation** — chem-symbol class using actual formula notation (H₂O, HNO₃) rendered in Bebas Neue as decorative typographic elements.
3. **Tabbed contact form** — Three distinct forms (Commission / Edition Enquiry / Studio Visit) under a single tab interface to segment visitor intent without multiple form pages.
4. **Edition status badges** — Three-state system (Available / Reserved / Sold Out) positioned as absolute overlay on edition card images.
5. **Press room badge** — Floating "55+ Years" badge on the press room image, positioned with negative offset for visual interest.

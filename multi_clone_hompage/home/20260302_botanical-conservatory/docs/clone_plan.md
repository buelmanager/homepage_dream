# Clone Plan — The Royal Botanical Conservatory

## Source Inspiration
Original fictional concept — no direct clone source. Design language draws from luxury cultural institution websites (RHS, Kew Gardens, Natural History Museum) reimagined as a dark-mode premium template.

## Differentiation
- Dark forest-green palette unique to botanical category
- Type E canvas grid hero with animated botanical-green grid and floating dots
- Spectral italic typography for dramatic serif headlines
- Seven-pavilion collection architecture unique to this template
- Seed bank and reintroduction process framing adds institutional authority

## Page Architecture
- 5 pages: index, about, collection, process, contact
- index: 13 sections including preloader, scroll indicator, canvas hero, stats, philosophy grid, collection grid, atelier split, process timeline, milestones, press swiper, form, footer
- Sub-pages: consistent dark navbar, page-hero pattern, GSAP reveal animations

## Technical Notes
- Hero uses HTML5 Canvas for animated grid — no external dependencies
- GSAP ScrollTrigger with immediateRender: false throughout
- Swiper.js for press testimonials
- All images via Unsplash CDN (validated)

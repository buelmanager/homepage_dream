## URL Format

All images use the following Unsplash CDN format:
```
https://images.unsplash.com/photo-{ID}?w={width}&q=80&auto=format&fit=crop
```

Parameters used:
- Hero / Gallery large: `w=1200` or `w=1600`
- Section images: `w=800` or `w=1000`
- All: `q=80`, `auto=format`, `fit=crop`

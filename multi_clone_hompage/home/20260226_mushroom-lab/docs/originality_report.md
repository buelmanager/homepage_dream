## Original Design Elements

### 1. Preloader — Mycelium SVG Network (Unique)
- Custom branching SVG with animated stroke-dashoffset reveal
- 12 branching paths from central node growing outward in sequence
- Spore node scale-in with back.out easing
- No other template in collection uses SVG path-draw animation

### 2. Hero Substrate Stats (Unique)
- Four floating stat panels at hero bottom: Species count, Michelin restaurants, delivery speed, temperature
- Data-driven luxury aesthetic — combines science with premium positioning

### 3. Species Grid with Hover Reveal (Distinctive)
- 6-card grid with CSS max-height transition revealing flavor/texture copy
- Scientific name in italic Cormorant Garamond as sub-label
- Species "tag" badge (Neuroprotective, Umami Master, etc.) — category taxonomy system

### 4. 5-Step Lab Process with Numbered Typography (Distinctive)
- Large ghost-number (opacity via border color) that transitions to accent on hover
- Process steps with ISO 5 badge floating on image corner
- Clean-room photography creates visual contrast with earthy species section

### 5. Science Section — Compound Tag Cloud (Unique)
- Beta-glucans, Triterpenes, Hericenones, Erinacines tag row beneath image
- 4 numbered benefits with specific clinical references (NGF, BDNF, 8-week studies)

### 6. Dual Scroll Indicator States
- Hidden during preloader, revealed via both preloader onComplete AND setTimeout(4000)
- GSAP ScrollTrigger fades out indicator when hero scrolls past viewport

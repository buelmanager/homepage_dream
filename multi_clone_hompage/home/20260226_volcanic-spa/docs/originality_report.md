## Origin Statement

IGNIS is an entirely original design created from brief. No existing website, template, or competitor page was used as a structural or visual reference. The design was developed from a brand concept brief specifying the volcanic spa concept, color palette, typography, and required page structure.

---

## Design Originality Assessment

### Color System — Original
The `#231212` / `#FF6030` / `#F0C080` palette was specified in the brief and is a bespoke combination. This volcanic crimson-to-lava-orange system is not found in any existing spa template library. The specific RGB values were chosen to satisfy dark section detection thresholds (avg ≥ 15) while maintaining brand integrity.

**Closest commercial reference:** None identified with matching palette.

### Typography Pairing — Original
Fraunces + Inter is an uncommon pairing in the luxury spa category, where most competitors use:
- Playfair Display (overused)
- Cormorant Garamond (overused in luxury)
- Libre Baskerville (accessible, not luxury)

Fraunces was chosen specifically for its variable optical sizing axis and unusual italic character — not commonly seen in spa/wellness templates.

### Layout Structure — Original
The layout architecture does not replicate any specific template:

| Element | Origin |
|---------|--------|
| Lava rise preloader | Original CSS animation — no known template uses upward gradient animation as lava metaphor |
| Geology radial diagram | Original — pure CSS concentric circle diagram representing Earth layers |
| Left-fixed scroll indicator | Common pattern adapted with accent color line + dot |
| Temperature badge overlay | Original pattern — temperature as product specification label |
| Seasonal calendar | Original 12-column dot grid — not a calendar widget, a visual status map |
| Voucher card visual | Original CSS gradient card mimicking physical gift voucher format |
| Package sidebar system | Original 2-column package card with colored sidebar for featured state |

### Content — Entirely Fictional
All brand content is original fictional copy:
- Dr. Sigrid Magnusdóttir: fictional character created for narrative depth
- Geological claims (3km water journey, 350mg/L silica, 4,000-year flow) are fictionally plausible but not based on real data
- Pool names (Insight Pool, Solar Pool, Obsidian Pool, Deep Heat) — original naming
- Package names (The Ember, The Lava Flow, The Magma) — original naming system based on volcanic heat intensity metaphor
- Pricing (€1,200 / €3,400 / €8,900) — original pricing architecture

# Originality Report — MERIDIAN Lighthouse Inn

## Summary

This template is an original creative work produced for the homepage_dream template library. All brand identity, copy, visual concepts, and structural choices are original and do not replicate any specific real-world hospitality brand or website.

## Brand Originality

### MERIDIAN Identity
- **Name "MERIDIAN"**: Original fictional brand name. Not referencing any existing hotel or inn brand. "Meridian" was chosen for its maritime connotations (navigational meridian lines, the meridian passage of celestial bodies) and its association with precision and the sea.
- **Tagline "Where Land Meets the Infinite Sea"**: Original composition. Not drawn from any existing hospitality brand.
- **Logo treatment "MERI*DIAN*"**: Split-word italic treatment with accent color is a typographic device used specifically for this brand — inspired by classic lighthouse logotype traditions.

### Brand Story Originality
- **Cape Meridian, Maine**: Fictional location. No real Cape Meridian exists in Maine.
- **The Aldrich family keeper lineage**: Entirely fictional. While "Aldrich" is a common Maine surname, the family narrative, dates, quotes, and story arcs are invented.
- **The 1924 "Great Atlantic Storm"**: Fictional event, though inspired by the real New England Hurricane of 1938 and the 1924 Atlantic storm season.
- **Chef Margaux Vidal**: Entirely fictional persona.
- **The Keeper's Table restaurant**: Fictional restaurant name and concept.
- **"Morning Fog Ritual"**: Original guest experience concept.

## Design Originality

### Color Palette
- Arctic Slate (P5) is a system-generated palette from the homepage_dream design system. Applied per spec to lighthouse/coastal aesthetics.
- The specific combination of `#141820` background with `#A0C4D8` accent for a maritime context is original.

### Layout Architecture
- The 5-page site structure (index/about/collection/process/contact) is a standard multi-page hospitality pattern common to the template library.
- The specific section ordering on index.html (Stats → Philosophy Grid → Collection → Captain's Quarters Feature → Journey → Heritage → Testimonials → Form) is an original arrangement for this template.
- The lighthouse tower timeline (index.html heritage section) with overlapping two-image layout is original to this template.
- The alternating full-width journey steps on process.html are an original structural choice for this industry/context.

### SVG Icons
- All SVG icons embedded in the pages are hand-crafted inline paths and do not reference any icon library.
- The lighthouse SVG in the preloader (tower + beam + water line) is an original illustration.

## Technical Originality

- All HTML/CSS/JS is hand-written for this template.
- The SplitText polyfill is a standard library component used across all homepage_dream templates (not specific to this template).
- The mousemove parallax implementation is a standard GSAP pattern adapted for the Type B hero specification.

## Inspirational References (not copied)

The maritime hospitality aesthetic was informed by general knowledge of:
- Classic New England lighthouse preservation projects
- U.S. Lighthouse Board architectural traditions (1880s–1910s)
- Cape Cod and Maine coastal inn hospitality conventions

No specific website, HTML code, or copy was used as a reference or reproduced in this template.

## Conclusion

**Originality Rating: High**

All content — brand identity, narrative, copy, structural layouts, and visual concepts — is original creative work produced for this template. No substantive portion of this work reproduces existing copyrighted content.

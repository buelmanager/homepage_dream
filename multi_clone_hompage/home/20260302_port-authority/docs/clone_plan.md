# Clone Plan — Meridian Port Authority

## Source Inspiration
Original fictional concept. Maritime/industrial aesthetic inspired by Lloyd's Register, ABP and Hamburg Port Authority — reimagined as a dark luxury template.

## Differentiation
- Steel-blue accent (#A0C4D8) unique in the collection — softer maritime blue vs. cyan tech
- Type C diagonal split hero with skewX CSS divider — geometric industrial character
- Bebas Neue all-caps for maximum authority and scale
- Commercial/logistics-focused page architecture
- Emergency 24/7 contact box — authentic maritime institution detail

## Technical Notes
- Hero diagonal: CSS skewX transform on pseudo-element creates the diagonal split
- GSAP x-slide animations (A3 personality)
- No canvas — relies on image-based hero

# ALTITUDE — Originality Report

## Summary

This template is an entirely original creative work. No existing website was cloned, reverse-engineered, or used as a structural template. All HTML, CSS, JavaScript, and copy was written from scratch specifically for this project.

## Original Elements

### Brand Identity
- Brand name "ALTITUDE" — original fiction brand
- Tagline "A New Perspective on Everything" — original copy
- Studio name, pilot names, certifications, stats — all fictional
- Contact details — all fictional (aviation-themed London addresses)

### Design System
- Colour palette — original derivation:
  - `#0E1520` navy background: original formulation
  - `#40C0F0` sky blue: original accent derived from sky/horizon metaphor
  - `#F0C840` gold: original secondary derived from golden hour photography
- Typography pairing Space Grotesk + Inter: original selection
- Scan-line HUD overlay: original creative concept for drone/aviation aesthetic
- Altitude meter badge on hero: original brand element

### Layout Architecture
- Multi-column spec table layout for equipment: original structure
- Tabbed contact form with three modes: original UX approach
- Airspace licensing zone status table: original informational design
- Left-side fixed scroll indicator: adapted from editorial design convention

### Animations
- Drone ascending SVG preloader: original SVG illustration and animation
- Hero letter stagger with GSAP: standard technique, original timing/parameters
- HUD scan-line animated overlay: original CSS animation technique
- Altitude counter animation: original JavaScript counter effect
- Spec item slide-in sequence: original choreography

### Copy
All website copy — descriptions, service explanations, pilot bios, FAQ answers, form labels — written as original fictional content for this studio persona.

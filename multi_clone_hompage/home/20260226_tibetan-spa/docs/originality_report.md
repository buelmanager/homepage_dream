# Originality Report — MANDALA Tibetan Healing Sanctuary

## Summary

MANDALA is an original design created from scratch. No specific real-world website was cloned or replicated. The project draws from general luxury spa and retreat website conventions while incorporating entirely original:

- Brand identity and naming
- Copywriting and content
- Layout compositions
- SVG artwork
- Colour system

---

## Original Creative Elements

### Brand & Identity
- **Name:** MANDALA — an original brand name chosen for its resonance with Tibetan spiritual geometry
- **Tagline:** "Ancient Healing. Elevated Living." — original composition
- **Logo treatment:** IM Fell English serif in letter-spaced uppercase — not sourced from any existing brand
- **Narrative:** All practitioner names, programme names, monastery history, and pricing are entirely fictional

### Visual Design
- **SVG Mandala preloader:** Hand-authored 8-petal mandala with rotating outer diamond petals. No third-party icon or SVG library used
- **SVG Prayer wheel:** Custom 8-spoke wheel with compass-direction petal accents — original
- **Healing art icons:** 4 custom SVG paths representing singing bowls, hot stones, steam, and meditation star — all original
- **Colour palette:** Original composition — saffron gold (#D4A020) against a warm dark monastery brown (#1C1510)

### Layout Architecture
- **Mist parallax system:** Three-layer mist overlay (gradient-bottom, flat mid-tone, blur band) — original atmospheric technique
- **Scroll indicator:** Left-side fixed with animated travelling gold line — original CSS keyframe animation
- **Alternating treatment sections:** `direction: rtl` technique for even/odd mirroring — original implementation
- **Tab-switching contact form:** Three distinct form types (treatment / retreat / general) with vanilla JS tab controller — original

### Copywriting
All text content is original, including:
- Philosophy section (Lung/Tripa/Beken Tibetan medical framework)
- Treatment descriptions (all 7 treatments)
- Retreat package inclusions (The Awakening, Sacred Alignment, The Transformation)
- Practitioner biographies (all 4 fictional healers)
- Monastery history timeline (1623–2026)
- Travel logistics section
- Contact form labels and placeholder text

---

## Reference Sources (Inspiration, Not Replication)

The following categories of sites were used as general reference for luxury wellness conventions — none were cloned or directly replicated:

- High-end spa/resort websites (layout conventions only)
- Tibetan medicine academic sources (for authentic medical terminology)
- Monastery photography (aesthetic direction only)

## Conclusion

MANDALA passes originality criteria as a fully original design composition. The only conventional elements used are standard luxury web design patterns (fixed navigation, full-screen hero, card grids) that are generic to the category and not protectable.

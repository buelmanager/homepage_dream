# ABYSSÉ Design System

## Colour Palette — P4 Deep Burgundy

| Variable | Hex | Usage |
|----------|-----|-------|
| `--bg` | `#1A0A0E` | Page background |
| `--surface` | `#241016` | Card/section backgrounds |
| `--surface2` | `#2C1420` | Nested surfaces |
| `--accent` | `#C96A8A` | Primary accent, CTAs |
| `--accent-light` | `#E090A8` | Hover states |
| `--accent-dark` | `#8A3A5C` | Active states |
| `--ivory` | `#F0DCE4` | Primary text |
| `--smoke` | `#A08088` | Secondary text |
| `--muted` | `#604A52` | Tertiary/footer text |
| `--border` | `#200C12` | Borders, dividers |

## Typography — F9 Spectral + Mulish

- **Spectral**: headings, hero title, pullquotes — elegant, literary serif
- **Mulish**: body text, navigation, labels — clean geometric sans

## Spacing

- Section padding: 120px vertical, 80px horizontal (desktop)
- Mobile: 80px vertical, 24px horizontal

## Hero Layout

Type D — Portraits + Stats: `display: grid; grid-template-columns: 1fr 1fr`

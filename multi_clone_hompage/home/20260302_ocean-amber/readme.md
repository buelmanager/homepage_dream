# BALTURA — Amber House

A complete luxury multi-page landing page template for a Baltic sea amber fine jewelry atelier in Gdańsk, Poland.

## Brand Concept

BALTURA is a three-generation family amber jewelry atelier on ul. Mariacka in Gdańsk — the historic amber street of the old city since the 14th century. Baltic amber, 44 million years old, is the foundation. Tagline: "Amber House."

## Pages

| File | Description |
|------|-------------|
| `index.html` | Main landing page: scroll-driven text transform hero, stats, philosophy, collection, atelier, process, heritage, press, commission form |
| `about.html` | Atelier and collection overview |
| `collection.html` | Collection and atelier information |
| `process.html` | Amber sourcing and craft information |
| `contact.html` | Commission information |

## Hero Type

**G — Scroll-Driven Text Transform**: `min-height: 200vh`, fixed background, sticky text wrap. Large typographic words (BALTIC / AMBER) transform on scroll via GSAP scrub. Background unfixes when scrolled past.

## Animation

**A4 Dramatic**: duration 1.1–1.3s, y: 40px, stagger: 0.15, ease: `power2.inOut`

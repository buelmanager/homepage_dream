# SALTERN — Maritime Distillery

A complete luxury multi-page landing page template for a maritime coastal copper pot distillery in Cornwall, UK.

## Brand Concept

SALTERN is a heritage copper pot distillery perched on the Cornish headland. Salt-air ageing, granite spring water, and three 1972 Speyside copper stills produce a range of single malts that cannot be made anywhere else. Tagline: "Maritime Distillery."

## Pages

| File | Description |
|------|-------------|
| `index.html` | Main landing page: diagonal split hero, stats, philosophy, spirits collection, distillery section, process, heritage timeline, press, tasting form |
| `about.html` | Distillery building history, copper still profiles |
| `collection.html` | Full spirits range with tasting notes |
| `process.html` | 4-step distillation process |
| `contact.html` | Split-layout visit/tasting booking form |

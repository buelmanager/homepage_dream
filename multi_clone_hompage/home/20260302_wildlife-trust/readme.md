# Verdania Wildlife Trust — 20260302_wildlife-trust

## Overview
Luxury landing page template for a fictional wildlife conservation trust. Deep forest green palette with Fraunces serif and Inter sans-serif. Type B parallax hero with Ken Burns layers.

## Brand
- **Name**: Verdania Wildlife Trust
- **Tagline**: Where Wild Things Endure
- **Industry**: Wildlife conservation, endangered species protection
- **Tier**: Free

## Design Specs
- **Hero**: Type B — Parallax dual-layer with mousemove interaction
- **Palette**: Forest night greens (#0F1A10 bg, #4DAF6A accent)
- **Fonts**: Fraunces (serif) + Inter (sans)
- **Animation**: A5 — power2.out, 1.0–1.4s, y 20–28px, stagger 0.09

## Pages
- `index.html` — Full landing page
- `about.html` — Mission, leadership, values, timeline
- `collection.html` — Conservation programmes grid
- `process.html` — Six-stage methodology
- `contact.html` — Form, info, map, social

## Key Sections (index.html)
1. Preloader with SVG path draw animation
2. Fixed scroll indicator with progress fill
3. Transparent navbar with blur-on-scroll
4. Type B parallax hero
5. Stats strip (4 counters)
6. Philosophy (3-col grid)
7. Programme collection (2×2 offset grid)
8. Atelier (2-col with parallax image)
9. Process timeline (5 steps)
10. Heritage milestones (4-col)
11. Press quotes (Swiper carousel)
12. Contact form (2-col)
13. Footer (4-col, var(--bg))

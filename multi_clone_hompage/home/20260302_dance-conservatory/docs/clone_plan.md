# Clone Plan — Mouvement Dance Conservatory

## Concept

A luxury multi-page template for a dance conservatory. Type C diagonal split hero creates immediate drama — the sharp diagonal line between the text panel and the full-bleed dance image captures the tension between structure and freedom that defines great dance. Deep rose/crimson palette evokes passion, physicality, and the stage.

## Design Decisions

- **Hero:** Type C diagonal split — left text panel clips with polygon, right panel is full dance photography
- **Color:** Deep red (#1A0A0E bg) with rose accent (#C96A8A) — evokes stage lighting, passion, physicality
- **Typography:** Bodoni Moda (tall elegant serif, italic weights) + Work Sans (geometric humanist sans) — period and contemporary dance together
- **Swiper:** Testimonials at 3-across on desktop

## Pages

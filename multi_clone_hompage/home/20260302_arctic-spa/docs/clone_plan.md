# Clone Plan — BOREAS Arctic Spa

## Concept
A luxury landing page for a fictional arctic cold therapy spa set on Norway's Lofoten Islands. The design draws inspiration from the austere beauty of nordic wellness culture combined with the scientific credibility of cold therapy research.

## Inspiration Sources
- Nordic spa and wellness architecture (dark, mineral, restrained)
- Cold therapy brands (Morozko Forge, Plunge, Wim Hof Method)
- High-end Icelandic spa design (Blue Lagoon Retreat aesthetic)
- Luxury hotel positioning (intimate scale, waiting list culture)

## Originality Decisions
- Arctic slate palette is original — not derived from any existing template
- DM Serif Display + Karla pairing is new to the batch
- Hero Type B with arctic parallax depth is distinct from other parallax templates
- Four-phase "Arctic Method" protocol content is wholly original
- Nordic mythology brand name (BOREAS) avoids cliché generic spa naming

## Section Structure (index.html)
1. Preloader
2. Scroll Indicator
3. Navigation (fixed)
4. Hero — Type B Parallax
5. Intro — 2-column with image
6. Philosophy — 3-card grid
7. Collection — 3 treatment cards
8. Stats Band — 4 counters
9. Process — 4-step horizontal
10. Testimonials — Swiper carousel
11. Gallery — 4-column grid
12. Press logos
13. CTA Band
14. Newsletter
15. Footer — 4-column grid

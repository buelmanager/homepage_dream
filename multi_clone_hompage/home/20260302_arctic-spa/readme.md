## Template Overview

A luxury multi-page landing page for an arctic cold therapy and glacial mineral spa. BOREAS is a fictional wellness brand set on Norway's Lofoten Islands, offering glacial immersion rituals, mineral spring soaks, and thermal contrast therapy.

- **Hero Layout:** Type B — Parallax Full-Screen with mousemove depth effect

- **Font Pair:** F6 — DM Serif Display + Karla

# TIDECRAFT — Glass Studio

A complete luxury multi-page landing page template for a coastal tidal glass blowing and sculpture studio in Cornwall, UK.

## Brand Concept

TIDECRAFT was founded by Luca Ferraro, trained on Murano for eleven years, who brought Venetian glass traditions to the Cornish coast. The ocean's tides serve as the design brief for every piece. Tagline: "Glass Studio."

## Animation

# CRESTILLE — Crystal Atelier

## Concept
Alpine gemstone and crystal fine jewelry atelier in Chamonix at 1,800m. Geological approach — every setting designed around the mineral's natural geometry. Full provenance documentation included.

## Color Palette — P2 Cool Obsidian
- Background: #101420 (near-black blue)
- Surface: #181E2A
- Accent: #4EE8FF (electric cyan/crystal blue)
- Ivory: #DCE8F0

## Typography — F8 Bodoni Moda + Work Sans
- Bodoni Moda italic for elegance and drama
- Work Sans for clean technical body text

## Hero — Type G Scroll-Driven Text Transform
Two giant words (ALPINE / CRYSTAL) scroll-transform outward as user scrolls. Fixed background image. Dramatic exit animation with gsap scrub.

## Animation — A4 Dramatic
Duration 1.1–1.3s, y: 40px, stagger: 0.15, ease: power2.inOut. Heavier and more theatrical than standard.

## Pages
- index.html: Full landing page with scroll-transform hero
- about.html: Founder story, manifesto, values, heritage timeline
- collection.html: 6 pieces with filter bar
- process.html: 5-stage process with paired images
- contact.html: Commission enquiry form

## Special Features
- Hero fixed background unfixes after scroll past to allow normal page flow
- Geometric SVG preloader (crystal/gem shape)
- Cyan accent color creates unique visual identity vs standard warm luxury

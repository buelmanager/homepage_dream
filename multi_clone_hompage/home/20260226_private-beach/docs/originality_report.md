# AZURA — Originality Report

## Summary
AZURA is an original design concept created from scratch. It is not a clone or recreation of any specific existing website. The design draws inspiration from the luxury hospitality category at large and represents an independent creative interpretation.

---

## Design Originality

### Concept
The "private island beach club" concept is a recognized hospitality category (e.g., Soho House, One&Only, Aman, Nikki Beach). AZURA is not based on or derived from any of these brands. It presents a fictional brand with an invented history, location, staff, and pricing.

### Layout Architecture
The page layout is original. No layout grid, section order, or content hierarchy is copied from an existing website. Key layout decisions:
- Hero stats bar at the bottom of the cinematic section (not seen in comparable templates)
- SVG compass rose floating element in hero (original decorative element)
- Experiences page with sticky category sub-navigation
- Membership benefits HTML comparison table
- 4-step visual process track on membership page

### Typography
Cormorant Garamond is a widely used luxury font (Google Fonts, free). Its pairing with Inter for body is a common and non-proprietary combination. All typographic scale, tracking, and sizing values are original.

### Color Palette
The deep ocean palette (#0F1E2E / #152438 / #20BFCC / #F0D080) is an original combination created for this project. It is not derived from any brand identity system.

### Copy
All written content — brand name, tagline, history, staff names, property descriptions, menu descriptions, membership tier names and benefits — is entirely original fiction. Chef "Alain Dumas" and "Inés Ramos Vilà" are fictional characters.

# Originality Report — 20260228_typographer-portfolio

## Assessment: ORIGINAL — No Clone Reference

### Source Inspiration (Non-Clone)

This template draws conceptual inspiration from the established visual language of professional type foundry portfolios — not from any single website or template. The following are genre references, not sources:

- **Klim Type Foundry** (klim.co.nz) — Dark palette, specimen-forward design
- **Colophon Foundry** (colophon-foundry.org) — Minimalist grid, editorial approach
- **Commercial Type** (commercialtype.com) — Specimen depth, filter UX
- **Emigre Magazine** historical aesthetic — Type as visual argument

### Original Design Elements

1. **Text-Driven Hero (Type G)** — The use of the brand name at 22vw scale as the primary visual is original to this template. The ghost text-stroke behind the main letterform and floating alphabet drift animation are unique design decisions.

2. **Type Specimen Card System** — The 2-column grid with numbered specimens, integrated alphabet samples, pangrams, and weight tags is a novel system designed for this template.

3. **Vertical Phase Number** — The rotated phase number (writing-mode: vertical-rl) alongside the 3-column process phase layout is an original structural device.

4. **Location + Form Split** — The commission page's dual-studio presentation with photographic location cards alongside the commission form is a unique UX pattern.

5. **Letterpress Workflow Sequence** — The 4-step letterpress proof process (Set → Lock → Ink → Translate) as a narrative sidebar is an original section.

### Colour Originality

P8 Onyx (#181818, #222222, #2A2A2A / accent #B0B0C0) is the design brief palette — used as specified. The application of slate-silver accent rather than warm gold or neon is a deliberate departure from typical portfolio templates in the dark-palette space.

### Content Originality

All copy — studio name (GLYPH), designer biography (Elara Voss), typeface names (Aldgate, Mitte, Folio Script, Pressmark, Kremlin, Spital, Raven Text, Inkwash, Finsbury, Blackletter No.3, Coppersmith), client names, studio addresses — is entirely fictional and original to this template.

# Pelagic Ocean Fund — 20260302_ocean-fund

## Overview
Premium luxury landing page for a fictional ocean restoration fund. Deep teal palette with Spectral serif and Mulish sans. Type G scroll-driven text transform hero.

## Brand
- **Name**: Pelagic Ocean Fund
- **Tagline**: Restoring the Living Sea
- **Industry**: Ocean restoration, marine conservation, plastic cleanup
- **Tier**: Premium ($49)

## Design Specs
- **Hero**: Type G — Scroll-driven large text transform (parallax words diverge on scroll)
- **Palette**: Deep teal ocean (#0A1818 bg, #4DCFB0 accent)
- **Fonts**: Spectral (serif) + Mulish (sans)
- **Animation**: A2 — power1.out, 1.4–1.6s, y 14px, stagger 0.06

# Celestial Society — Astronomy Club Landing Page

**Slug:** 20260302_astronomy-society
**Category:** Club / Society
**Tier:** Free
**Hero Layout:** Type G — Scroll-Driven Text Transform

## Overview

A full luxury multi-page landing page template for an amateur astronomy society. The design uses a deep cosmic palette of navy and cyan, with Spectral serif and Mulish sans-serif typography. The signature hero section features large typographic words that transform and disperse as the user scrolls, revealing the content beneath.

## Pages

- `index.html` — Main landing page with all 13 sections
- `about.html` — Society history, team, and values
- `collection.html` — Events calendar with filter interface
- `process.html` — Membership tiers and FAQ
- `contact.html` — Contact form and details

## Key Animations

- Hero: GSAP ScrollTrigger scrub — words diverge to edges on scroll
- Stats: CountUp on enter
- Cards: Staggered fade-up with power2.inOut
- Atelier: Bilateral slide-in

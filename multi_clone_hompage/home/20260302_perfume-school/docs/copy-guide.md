# Copy Guide — L'École du Nez

## Voice
- Intellectual, sensory, poetic but precise
- French inflection without condescension
- Uses fragrance terminology correctly and with authority
- Celebrates the nose as a scientific and artistic instrument

## Key Messages
1. The nose can be trained — it is not a fixed gift
2. Grasse location gives unparalleled access to raw materials
3. Small cohorts, personal Socratic instruction
4. Complete professional training available via Diploma
5. Nature and synthetic palette treated without ideology

## Avoid
- Romantic clichés about fragrance
- Gendered language about perfume
- Claims about "unique" scent experiences
- Over-use of French phrases

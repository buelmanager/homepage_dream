# Originality Report — SANCTUM Private Members Club

**Project:** 20260226_private-members-club
**Date:** 2026-02-26

## Original Design Decisions

### Brand Identity
- Brand name "SANCTUM" — original fictional brand, not derived from any real club
- Tagline "By Invitation Only" — original positioning statement
- Est. 1887 fictional founding year with London Mayfair provenance
- Fictional founder "Lord Alistair Pemberton" for heritage quote

### Layout Innovations
- Diagonal split hero (Type C) with atmospheric image and copy panel
- Rotating badge element (CSS animation + counter-rotate inner)
- Crest SVG drawn with stroke-dashoffset animation (original crest design)
- Letter-by-letter preloader with fill bar progress indicator
- Facility cards with max-height description reveal on hover

### Color System
- Warm dark palette #1A1612 — original, not copied from any reference
- Aged gold #C9A96E — distinct from typical gold (#FFD700) — warmer, more muted
- Cognac #8B4513 as secondary accent — reflects club atmosphere

### Copy / Content
- All text written originally for this project
- Member testimonials are fictional (James Hartwell, Elena Crowthorne, Sir Richard Vane)
- Events are fictional (The Future of Civilization symposium, Emerging Masters exhibition)
- Tier names (Associate / Fellow / Patron) — original hierarchy naming

### Technical
- SplitText polyfill: identical to project standard (not original — reused)
- GSAP animations: original timing and parameters
- Custom SVG crest designed inline
- Form design with diagonal background pattern (original CSS)

# QARMID — Clone Plan

## Project Brief
Luxury desert oasis retreat with 24 private villas in the Moroccan Sahara.

## Design Direction
Deep burgundy palette evoking desert rose and rich Moroccan textiles. Playfair Display for classical luxury authority. Type D hero with portrait grid creates immediate visual impact.

# QARMID — Oasis Retreat

A complete luxury multi-page landing page for a private desert oasis retreat.

## Brand Concept

QARMID is a fictional 24-villa luxury retreat in the Moroccan Sahara. Founded by architect Yassine Qadir, it offers absolute privacy, Saharan wilderness, and total stillness. Tagline: "An oasis of absolute luxury."

## Pages

| File | Description |
|------|-------------|
| `index.html` | Main page with Type D portrait hero, villa grid, philosophy, experiences, process, testimonials, booking CTA |
| `about.html` | Founder story, values, team |
| `collection.html` | Full villa guide with alternating layout |
| `process.html` | 5-step planning timeline |
| `contact.html` | Reservation enquiry form |

## Design System

| Token | Value |
|-------|-------|
| `--bg` | `#1A0A0E` (deep burgundy dark — avg 21.3) |
| `--surface` | `#241016` |
| `--accent` | `#C96A8A` (desert rose pink) |
| Font (heading) | Playfair Display (classic serif, italic) |
| Font (body) | Lato (geometric, readable) |

## Hero Type
Type D — Portrait + Stats grid (2-column: content panel + 3 portrait cards)

## Animation Style
A1 Standard — duration 1.0–1.2s, y:24px, stagger:0.10, ease:'power2.out'

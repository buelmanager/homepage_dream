# Clone Plan — Grand Cuisine Institute

## Concept

A luxury culinary school template with a Type E canvas-grid hero. The geometric grid pattern in the hero alludes to the precision and systematic thinking required by classical French cuisine. Deep amber/terracotta palette evokes spice, fire, and the warmth of a working kitchen.

## Design Decisions

- **Hero:** Type E canvas grid — JavaScript draws a fine grid with accent dot intersections, radial gradient fades to centre, creating a distinctive non-photographic hero that stands apart from standard food photography approaches
- **Color:** Dark amber (#1C1008 bg) with terracotta accent (#D4612A) — warm, earthy, evokes Burgundy and the kitchen
- **Typography:** Libre Baskerville (authoritative serif with italic) + Source Sans 3 (clean functional sans) — old-world authority and modern clarity together

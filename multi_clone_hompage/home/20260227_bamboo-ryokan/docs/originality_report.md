# Originality Report — KURETAKE Bamboo Ryokan & Onsen

## Summary

This template is an original design and concept. No existing website was cloned or copied. The design draws on broadly established conventions in luxury hospitality web design, combined with the project's specified design system (palette P10, font F4, animation A2, hero layout Type G).

## Design Originality

### Layout Patterns Used (Industry Standard)

The following layout patterns are broad hospitality industry conventions, not derived from any specific source:
- Full-screen hero with overlay gradient + centered typography
- Fixed navbar transitioning from transparent to frosted glass
- Stats bar below hero
- Split-screen text/image alternating sections
- Swiper carousel testimonials
- Multi-column footer

### Type G Hero — Scroll-Driven Text Transform

The scroll-driven word divergence animation (two large words splitting horizontally as user scrolls) is an established motion design pattern in luxury web design. The specific implementation — GSAP `onUpdate` driving `xPercent` on two words at differing rates — is original code written for this project.

### Philosophy Grid (三 Kanji Icons)

Using single Japanese kanji characters as section icons is a recognizable Japanese branding convention (used widely across cultural institutions, luxury goods, and hospitality). The specific content — Ma / Wabi / Sabi and their interpretations — is original prose.

### Guest Journey — Kanji Step Numerals

Using 一二三四五 (ichiniisansishigo) as step markers in a process section is original to this template within the project's template library.

## Content Originality

All body copy, testimonials, narrative text, chef names, room descriptions, ritual descriptions, pricing, policy language, and brand storytelling are original, written for this template. No content is lifted or adapted from any existing hospitality brand, travel publication, or web source.

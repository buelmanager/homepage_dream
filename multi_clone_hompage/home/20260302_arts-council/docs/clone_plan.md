# Clone Plan — The National Arts Council

## Source Inspiration
Original fictional concept inspired by Arts Council England design language, reimagined as a dark luxury template.

## Differentiation
- Deep purple palette unique in the collection
- Type D hero with 2×2 portrait image grid — strong visual impact without canvas dependency
- Spectral italic for emotive headline treatment
- Grants-focused page architecture (collection.html = grants, not products)
- A4 animation personality: slower, more deliberate y:40px reveals

## Technical Notes
- No canvas element — hero relies on CSS grid of images
- GSAP y:40 reveals throughout (A4 personality)
- Purple accent creates visual distinction from green (botanical) and cyan (science/space) templates

# Clone Plan — Lumina Cultural Centre

## Overview
Multi-page luxury landing site for a municipal city cultural centre.

## Design Decisions
- **Hero Type D:** Portraits + Stats grid chosen for its ability to showcase multiple venue/programme images alongside key statistics, creating an immediate impression of scale and activity.
- **Colour Palette:** Deep navy (#141820) with steel blue accent (#A0C4D8) evokes civic authority and cultural prestige.
- **Typography:** Libre Baskerville (serif) for headings — classical authority. Source Sans 3 (sans) for body — modern accessibility.

## Sections (index.html)
1. Preloader (SVG circle draw + brand name)
2. Scroll Indicator (fixed left)
3. Navbar (blur on scroll)
4. Hero Type D (portraits grid + stats)
5. Stats Strip (4 counters)
6. Philosophy (3-col grid)
7. Exhibitions Grid (2x2)
8. About/History (2-col)
9. Mission Timeline (5 steps)
10. Milestones (4 items)
11. Press Quotes (Swiper)
12. Contact/Visit Form
13. Footer

## Subpages
- about.html: Organisation history, leadership team, values
- collection.html: Current programme with filter bar
- process.html: Mission pillars, education stats, community work
- contact.html: Visit info with full contact details and enquiry form

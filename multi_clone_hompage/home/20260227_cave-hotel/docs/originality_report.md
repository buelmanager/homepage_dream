## Summary

GROTTO is a wholly original luxury hotel landing page concept. No existing website, template, or design system was referenced as a source to copy. The concept was generated from the design brief specifying: cave hotel, Midnight Purple palette, Cinzel + Crimson Pro typography, Type B hero layout.

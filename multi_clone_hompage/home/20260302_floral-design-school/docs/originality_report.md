# Originality Report — Bloom & Form Floral School

## Summary
This template is an entirely original design created from a design brief. No existing website was cloned or directly replicated.

## Original Elements

### Brand
- "Bloom & Form" is a fictional brand created for this template
- All copy, taglines, and messaging are original
- Faculty names (Adrienne Cole, Pierre Moreau, Sae Nakamura) are fictional

### Design
- Hero Type E (Grid/Pattern Canvas) is an original layout pattern from the homepage_dream system
- Color palette (Forest Night) is original — #0F1A10 bg with #4DAF6A accent
- Canvas grid animation is custom-written JavaScript

### Content
- Three philosophy principles (Ma, Wabi, Kata) reference real Japanese aesthetic concepts but the descriptions are original prose
- Program descriptions are original
- All testimonials and press quotes are fictional

## Palette Originality
Forest Night palette is unique within the homepage_dream template collection. The deep forest green background (#0F1A10) combined with the emerald accent (#4DAF6A) has not been used in previous templates.

## Typography Originality
DM Serif Display + Karla pairing (F6) not previously used in the 20260302 batch.

## Compliance
- No copyrighted images used (all Unsplash free-to-use)
- No copyrighted text used
- No direct website design replication

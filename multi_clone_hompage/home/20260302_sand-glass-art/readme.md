# FULGURITE — Sand Glass Studio

A complete luxury multi-page landing page for a Saharan desert glass art studio.

## Brand Concept

FULGURITE is a fictional desert glass art studio in the Tassili n'Ajjer, Algeria. Founded by geologist Dr. Karim Ouali and sculptor Yasmine Chafik, the studio creates art from fulgurite — hollow glass tubes naturally formed when lightning strikes desert sand. Tagline: "Where lightning meets sand."

## Pages

| File | Description |
|------|-------------|
| `index.html` | Main landing page with canvas grid hero, manifesto, collection, philosophy, process, atelier, testimonials, booking form |
| `about.html` | Founder story and team |
| `collection.html` | Full works archive (2-column layout) |
| `process.html` | 5-step creation process timeline |
| `contact.html` | Commission enquiry form |

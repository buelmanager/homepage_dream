# FULGURITE — Clone Plan

## Project Brief
Desert glass art studio with industrial-minimal aesthetic. Products are fulgurite (lightning glass) art works.

## Design Direction
Onyx Stone palette — near-black, cool silver accent. Bebas Neue for massive typographic impact. Canvas grid hero creates technical, gallery-like precision aesthetic. Type E hero with corner brackets frames the composition.

# Grand Touring Vintage Club — Vintage Auto Club Landing Page

**Slug:** 20260302_vintage-auto-club

## Overview

A premium luxury multi-page landing page for a vintage automobile club. The design features bold Bebas Neue display typography, a monochrome graphite palette (#181818), and a chrome accent. The diagonal split hero divides text content from a full-bleed classic car photograph.

## Pages

- `index.html` — Full landing page
- `about.html` — Club history and founding members
- `collection.html` — Events calendar with rally details
- `process.html` — Membership tiers
- `contact.html` — Contact form

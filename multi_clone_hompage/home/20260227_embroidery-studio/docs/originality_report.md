This template is an original creative work. No existing website was cloned, copied, or used as a direct reference. All content, layout structures, brand narrative, and visual design decisions are independently conceived.

- "Broderie" is the French word for embroidery — a natural, generic term for the industry.
- The name is not taken from any existing business known to the author.
- The brand identity (BRODERIE / "Every Stitch, a Meditation") is original.

### Tagline: "Every Stitch, a Meditation"
- Original phrase. Not borrowed from any existing brand, publication, or campaign.

## Design Originality

### Layout
The five-page layout structure was designed independently. No specific existing website was used as a template or reference.

### Hero Type E (Canvas Grid)
The animated canvas grid is an original implementation. The concept draws on:
- General cross-stitch fabric grid patterns (public domain aesthetic)
- The dot-grid animation pattern (a common decorative canvas technique)
Neither is proprietary.

The specific Deep Burgundy combination (`#1A0A0E`, `#C96A8A`, `#F0DCE4`) is an original selection. Burgundy palettes are widely used in luxury design; this specific combination does not replicate any known brand palette.

CSS border-corner elements are a generic UI technique. The specific application here (embroidery hoop / museum frame reference) is original.

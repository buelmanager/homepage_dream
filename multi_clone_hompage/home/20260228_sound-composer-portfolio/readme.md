# RESONANCE — Sound Design & Musical Composition

A luxury portfolio template for composers and sound designers. Features a deep teal color palette, typographic hero (Type G), and DM Serif Display + Karla font pairing.

## Pages

- **index.html** — Main portfolio landing page with Type G text-driven hero
- **about.html** — Biography, discography, filmography, and awards
- **collection.html** — Full works grid with category filter (Film/Game/Album/Ambient)
- **process.html** — 5-phase composition process, studio walkthrough, software list
- **contact.html** — Project inquiry form, collaboration types, rates overview

## Design Specs

| Property | Value |
|---|---|
| Hero Layout | G — Text-Driven Typography |
| Color Palette | P7 — Deep Teal |
| Font | F6 — DM Serif Display + Karla |
| Animation | A2 — Whisper (1.4–1.6s, y:14px) |
| Tier | Free |

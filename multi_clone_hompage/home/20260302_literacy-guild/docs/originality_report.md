# Originality Report — The Literacy Guild

## Brand Identity
Completely fictional brand. "The Literacy Guild" is an original name not associated with any real organization. All staff names (Eleanor Hartley, Harold), locations (Millhaven, NH), and statistics are invented.

## Content Originality
- All program names and descriptions are original
- Founder story is fictional
- Press quotes are invented (attributed to fictional publications)
- All statistics are illustrative, not based on real data

## Design Differentiation
- Hero layout Type G is distinct from the majority (Type A) in the template library
- Cool blue-navy palette is unique among nonprofit templates in the library
- Horizontal x-slide animation (A3) differentiates from the more common y-axis reveals
